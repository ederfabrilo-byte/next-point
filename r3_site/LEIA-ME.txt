==========================================
COMO HOSPEDAR (CAMINHO RÁPIDO — DIAS, NÃO SEMANAS)
==========================================

OPÇÃO A) Subir como site estático (recomendado para começar)
  1. Apontar o domínio www.r3cap.com.br para um serviço de hospedagem estática:
     - Netlify (https://www.netlify.com/) — gratuito, drag-and-drop da pasta
     - Vercel (https://vercel.com/) — gratuito
     - GitHub Pages — gratuito
     - Cloudflare Pages — gratuito
     - Ou hospedagem tradicional com FTP (Locaweb, KingHost, UOL Host)
  2. Subir o conteúdo da pasta r3_site/ inteira para a raiz do site.
  3. Configurar o DNS para apontar para o servidor de hospedagem.

OPÇÃO B) Importar no WordPress (caminho institucional definitivo)
  1. Instalar WordPress em uma hospedagem com PHP/MySQL (hostgator, UOL Host, etc.)
  2. Instalar um tema profissional. Sugestões para o visual desenhado:
     - Astra Pro
     - GeneratePress
     - Kadence
     (qualquer um destes permite controle das cores azul-marinho/dourado)
  3. Ir em Ferramentas > Importar > WordPress.
  4. Instalar o plugin "WordPress Importer" se solicitado.
  5. Carregar o arquivo r3-wordpress-import.xml.
  6. Atribuir todas as páginas ao usuário administrador.
  7. As 9 páginas serão criadas automaticamente.
  8. Ir em Aparência > Menus, criar menu principal com: Início, Sobre, Serviços,
     Equipe, Contato, e menu de rodapé com as 4 políticas.
  9. Ir em Configurações > Leitura > Página inicial: definir como "Início".
